# Documentation statistics – Modelica Standard Library

Generated by a static scan of all `.mo` files in this repository (2752 files, 7913 classes, 38903 component declarations). Criteria follow the Modelica documentation guidelines (`Modelica.UsersGuide.Conventions.Documentation`) and the *modelica-documentation-improvement* skill: every class should have a description string and an HTML `Documentation(info=...)` section; every component (variable, parameter, sub-model, connector) should have a description string.

Unless stated otherwise, numbers refer to the library **`Modelica`** only; the other libraries in the repository are summarized in [Other libraries](#other-libraries).

## Definitions

- **Long class**: `model/block/connector/record/package/function/class ... end X;`
- **Short class**: `type X = Real(...)`, `package Medium = ...`, enumerations, etc. Only the description string is evaluated for these.
- **Class extends**: `redeclare function extends density` etc. They are reported separately because their documentation lives in the base class.
- **Info size**: number of words of the `info` text after stripping HTML tags. **Little or no documentation** = no `info` or fewer than 25 words.
- **Description missing**: no description string or an empty `""`.

## Method and limitations

- Custom tokenizer/parser (Python); comments and strings handled, no full semantic analysis. Parsed class counts were cross-checked against `end <Name>;` occurrences per file (residual mismatches are caused by `end X;` text inside HTML strings).
- Components declared in `extends` modifiers or inherited from base classes are not counted (only the declaring class is). Redeclarations inside modifiers are not counted as classes.
- `ModelicaReference` documents keywords via classes with HTML-only content; its statistics are not representative.
- Raw data (CSV/JSON with file and line for every finding) was written to the scratchpad directory of the analysis session.
